# Features

## Available now

* The window of LightCreator's look: own frame and title bar, start screen, control bar, status bar, a Properties tab (position and size, rotation, mirror, alignment), the clipart gallery (310 included pictures, your own, online search), the colour schemes, fonts and the 30 languages of baseCreator.
* Reading SVG, PDF and Illustrator (PDF-compatible) files into a scene of shapes.
* The editor of baseCreator: drawing tools, selection, node editing, undo and redo, copy and paste, group, align, flip, rotate, order, grid and snapping.
* Menus (with the native macOS menu bar and recent files), icons, tool palette, arrange bar, View options and the About window of baseCreator.

## Planned

Nothing below exists yet; the list is a plan, not a promise.

* Project files, a configurable work area, text (the text tool needs a font dialog).
* Tool library: end mills, ball nose, V-bits; feeds and speeds per material.
* Operations: profile (inside, outside, on the line), pocket, drill, engrave, with tabs and multiple depth passes.
* Tool path preview and time estimate.
* G-code for GRBL (and other controllers), with post-processor settings.
* Machine control: connection, jogging, homing, probing, streaming.
* Project files, undo and redo, units in mm and inches.
* Translations of MillCreator's own texts (the shared ones are translated in baseCreator).
