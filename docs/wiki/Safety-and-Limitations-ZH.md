# 安全与限制

> 已确认 MillCreator 可以正常工作的机器，以及如何添加你的机器：[TESTS_ON_DEVICES.md](https://github.com/michalsarna/MillCreator/blob/main/TESTS_ON_DEVICES.md)。

> ⚠️ 铣床可能会伤害你，并损坏工件、刀具和机器本身。本程序还很年轻，**已在 TwoTrees TTC450Pro 上测试并能正常工作，但未在其他机器上测试**。使用风险由你自行承担。

* **先在空中测试：** 把机器抬高，使刀具碰不到任何东西，运行 G-code 并观察路径。然后在一块便宜的材料上运行。
* 佩戴护目镜和耳罩，夹紧工件，把手放在停止按钮附近，切勿让运行中的机器无人看管。
* 现成刀具的 **速度和进给** 是保守的起点；它们没有在你的机器上测试过。
* **检查零点：** G-code 从设备中设定的机器零点（哪个角）开始计算，Z = 0 位于材料顶面。如果你使用了 **文件 → 项目设置…**（**File → Project setup…**），它会从你在材料上选择的零点开始计算（G54 使用该零点：请在机器上的对应位置设定它），并在你要求时，Z 从材料底部算起。请在你的机器上进行相同的设定，并在刀具位于空中时观察最初的几次移动。
* **测试的内容：** 刀具路径的几何（与线条的距离、走刀、安全高度）、刀具库及其检查和文件、设备文件、项目文件以及 G-code 文本，在每次更改时都会进行自动测试。本 wiki 中的图片由程序本身渲染。

## 它不做的事情
* 它可以 **连接到 GRBL 机器并以流式方式发送任务**（连接、回原点、边框、开始、停止）；这已在 TwoTrees TTC450Pro 上试用过，**未在其他机器上试用**。请在主轴关闭且刀具位于空中的情况下开始，并守在机器旁；停止按钮会通过软复位中止任务。
* 边框在安全高度、主轴关闭的状态下沿工件的外框走一圈：请确认安全高度上确实没有障碍。
* 不检查与压板的碰撞，也没有刀具长度补偿（对刀仪会为新刀具设定 Z）。连接桥由程序放置（均匀分布）或在工作区上手动放置。
* **V 雕：** 无论各环之间的距离如何，侧壁都是精确的，但宽图形的平底由 V 形刀本身切削（会留下凸棱、程序很长；程序会给出提示）：请在型腔图层中使用平底刀来加工平底。镶嵌件的凸件雕刻在一块材料的背面：请把其图形镜像。
* 斜坡、螺旋、连接桥以及顺铣 / 逆铣的选择已在几何上以及在模拟器中针对 GRBL 固件进行了测试，**未在真实机器上测试**：请先在废料上、主轴关闭的情况下试用新的设置。只有足够高的连接桥才能固定零件：当连接桥与切削一样高时，程序会发出警告。螺旋下刀需要空间：放不下时，会改用沿轮廓斜坡。
* 超出工作区的图形会被报告，但不会被移动。
* 图片只在使用 **图片**（**Picture**）操作的图层上被铣削；在其他任何图层上只会显示（并给出警告）。文本按其轮廓铣削（沿轮廓走线）。
* 3D 视图显示铣削到滑块所在位置的材料（基于网格，小任务的网格更细）；它是供查看的画面，而不是测量结果。
* 时间是估算值。

## 新增且尚未在真实机器上试用的功能
以下所有内容都通过单元测试、渲染以及（对于会改变 G-code 的部分）在模拟器中针对 GRBL 固件进行了测试，**未在真实控制器上测试**。请先在主轴关闭、刀具位于空中的情况下逐一试用。

* **换刀装置**（`T<n> M6`，不暂停）：仅适用于支持 M6 的控制器（grblHAL、FluidNC）；普通 GRBL 会返回错误。没有换刀位号的刀具会使机器像以前一样停下。
* 每个图层的 **冷却液和吸尘器**（M7 / M8 / M9 以及设备自己的代码行）：随图层开启，在换刀之前和结束时关闭。未在模拟器中运行。
* **倍率调整、保存的位置、寻找中心、冷却液按钮：** 实时命令以及在机器坐标（`G53`）中的点动移动。保存的位置如果比刀具高，会先上升，然后横向移动，再下降：请确认路径上没有障碍。寻找中心用于孔，会沿 X 和 Y 移动探针；请在探针悬在孔中时启动它。
* **Duet / RepRapFirmware：** 主板自行运行上传的程序；**除了停止（通过网络发送的 `M0`）之外，无法从这里停止机器**，也没有倍率调整或点动。请把手放在机器自身的急停开关上。Smoothieware 像 GRBL 一样以流式方式发送，尚未在真实主板上试用。
* **用于 Mach3 / Mach4 / UCCNC 和 LinuxCNC 的后处理器**（插件 G-code dialects）是根据手册编写的：运行之前请先阅读文件。
* **作为浮雕的 3D 模型** 是从上方观察的：倒扣部分会丢失，最高点不切削，模型周围的部分会被清除到其最低点。
