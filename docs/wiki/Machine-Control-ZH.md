# 机器控制

> 已确认 MillCreator 可以正常工作的机器，以及如何添加你的机器：[TESTS_ON_DEVICES.md](https://github.com/michalsarna/MillCreator/blob/main/TESTS_ON_DEVICES.md)。

MillCreator 通过 **控制**（**Control**）标签页和 **机器**（**Machine**）菜单驱动 GRBL 机器。所有这些都来自 baseCreator，因此 MillCreator、PenCreator 和 LightCreator 的行为相同。**仅在 TwoTrees TTC450Pro 上测试过**：请在刀具抬起或不装笔的情况下测试，并把手放在停止按钮上。

## 读取机器信息

在 **设备**（**Device**）标签页上连接。程序会读取控制器（`$I` 读取其固件，`$$` 读取其设置，`$G` 读取其状态）。在设备设置的 **机器**（**Machine**）页面上，**为设备使用这些值**（**Use these values for the device**）把控制器中的行程、主轴转速和移动速度复制到设备中，这样你就不必手动输入。新设备也可以从 **常见机器尺寸…**（**A usual machine size…**）开始（仅作为起点）。

## 控制标签页

* **位置**（**Position**）：X、Y 和 Z 的工件位置和机器位置，以大号数字显示。**X0 Y0 Z0**（位于各轴左侧）把刀具所在位置设为工件零点（`G10 L20`）；单击数字可输入位置。其下方有：**全部归零**（**Zero all**）、**X 和 Y 归零**（**Zero X and Y**）、**移到 X0 Y0**（**Go to X0 Y0**，先上升到安全高度）和 **Z 到安全高度**（**Z to safe height**）。**坐标系**（**Coordinates**）选择 G54 … G59。
* **移动**（**Move**）：XY 和 Z 每次单击的移动距离是一个可以输入的字段；旁边的按钮把一个值填入其中（XY 0.1 … 100，Z 0.1 … 20；这些值在设备设置的 **点动**（**Jogging**）页面中设置）。**速度**（**Speed**）为设备的 XY 和 Z 速度（在这里的更改持续有效，直到设备本身的设置更改）。
* **点动按钮**（**Jog buttons**，大按钮，位于中间）：方向箭头、**Z▲ Z▼**；方块按钮停止移动。单击一次即移动一次。启用 **按住移动**（**Hold to move**）时，按住按钮期间刀具一直移动，松开时停止。**键盘**（**Keyboard**，默认关闭）使用方向键和 Page Up / Page Down，按所选步长移动。

* **任务选项**（**Job options**，位于边框和从某行开始…下方；仅本次会话有效，不保存；可以一起使用或单独使用，它们会改变 G-code、预览和时间估算）：**一次一个元素**（**One element at a time**）在开始下一个元素之前，完整切削每个元素——一个组（即使跨多个图层）或不属于任何组的图形——包括其所有图层及其所有走刀，先切离机器零点最近的元素（关闭时：一个图层接一个图层）。它适用于使用同一把刀具的图层：刀具不同时，每次切换都会换刀（暂停）。**仅所选内容**（**Selection only**）只切削在保存 G-code 或开始任务时工作区上被选中的图形；没有选中任何内容就意味着没有内容要切削。
* **预览是一个标签页：** **预览…**（**Preview…**，位于工作区上方）把预览作为工作区的标签页打开，与图纸和摄像头视图并列。右键单击该标签页并选择 **在单独窗口中打开**（**Open in a separate window**）可让它拥有自己的窗口；**返回主窗口**（**Back to the main window**，或关闭该窗口）把它放回去。标签页的叉号关闭预览。参见 [3D 视图与 G-code](3D-View-and-G-code-ZH)。
* **将 3D 视图导出为 STL：** 预览按钮栏中的 *下载* 图标（**将铣削后的工件导出为 STL…**（**Export the milled piece as STL…**））把铣削后的工件保存为二进制 STL 模型：带有刀具沟槽的坯料，到滑块所在位置为止（在末尾时为整个任务），单位为毫米，视图的左下角位于 0, 0，坯料顶面位于材料厚度处。刀具以其真实形状（平底、球头、V 形……）沿切削路径扫掠，因此表面精细程度取决于最小的刀具（大任务使用较粗的网格）。铣削 → *将浮雕导出为 STL…*（*Export relief as STL…*）是另一种导出：仅导出图片的浮雕。
* **主轴**（**Spindle**，MillCreator）：转速以及 **开启**（**Switch on**）/ **关闭**（**Switch off**）（`M3 S…` 和 `M5`），用于试运行主轴。当控制器的范围（`$30`）不是设备的最高转速时，S 值会按该范围换算。

## 探测（MillCreator）

在设备设置的 **探针**（**Probe**）页面中，说明你使用的是 **对刀板**（**touch plate**，其厚度及其侧面厚度）还是 **3D 触发式探针**（**3D touch probe**，触碰时的 Z 偏移和测球直径），以及失败距离、两种速度和回退距离。在控制标签页上：

* **探测 Z**（**Probe Z**）——刀具下降直到触碰（先快速，后退，再慢速），然后把 Z 设为对刀板的厚度。请先把对刀板放在刀具下方。
* 当探针输入已经处于闭合状态时，不会进行探测：否则刀具会被压在对刀板上。通过触碰对刀板来测试接线：输入会显示为 *闭合*（*closed*）。
* **宏**（**Macros**）：发送你编写的 G-code 的按钮（设备设置的 **宏** 页面）。方括号中的变量在发送宏时被替换：`[posx] [posy] [posz]`（工件位置）、`[mposx]` …、`[xmin] [xmax] [ymin] [ymax]`（任务的外框）、`[safez]`、`[prbx] [prby] [prbz]`（最后一次探测）。宏中不允许使用 `$RST`。同一页面上还有在每个任务 **之前** 和 **之后** 运行的 G-code（停止后也会运行）。

### 倍率调整、冷却液和保存的位置

* **倍率调整**（**Overrides**，GRBL 1.1 及更新版本，在控制器报告后显示）：任务运行期间，以 10% 和 1% 的步长更改 **进给** 和 **主轴** 转速，恢复到 100%，或把 **快速移动** 减慢到 50% 或 25%。当前的百分比会显示出来。这是 GRBL 的实时倍率调整，因此会立即生效，并且不会改变程序。
* **冷却液**（**Coolant**）：*雾化*（*Mist*，M7）、*喷淋*（*Flood*，M8）和 *关闭*（*Off*，M9）。图层可以自行要求使用冷却液（参见图层与操作）。机器通常把吸尘器接在 M8 上。
* **保存的位置**（**Saved positions**，GRBL 1.1 及更新版本）：*保存此处*（*Save here*）记住刀具所在的位置（机器位置，带名称）。名称按钮会返回该位置：如果该位置比刀具当前高，先上升，然后横向移动，再下降。列表保存在共享数据文件夹中的 `saved_positions.json` 中，因此每个程序都有相同的位置。
* **寻找中心**（**Find the centre**，在探测部分中）：探针悬在孔中，大约位于中间并处于你想要的深度。它触碰左侧和右侧，移到两者中间，触碰前侧和后侧，移到中间，并把该点设为当前坐标系的 X 和 Y 零点；状态行会给出孔的尺寸。它不处理 Z：请先探测 Z。它用于孔；对于凸台，请手动绕其移动探针并探测边缘。触碰失败或报警会使其停止。
* **换刀装置**（**Tool changer**）：能够自行更换刀具的机器（grblHAL、FluidNC：它们支持 M6；普通 GRBL 不支持）在设备设置中开启（*主轴*：*换刀装置*）。这样每把刀具都需要在刀具库中设置 **换刀位号**（**changer number**），程序会用 `T<number> M6` 调用刀具，而不是以 `M0` 暂停；换刀时冷却液和吸尘器会被关闭。
* **沿轮廓走边框**（**Frame round the outline**）：位于边框按钮旁边：边框沿切削的轮廓（橡皮筋式的凸包）走一圈，而不是沿其外框。

## 运行任务

* **开始**（**Start**）以流式方式发送整个任务；**从某行开始…**（**From line…**，*机器* 菜单中也有）从程序的某一行开始：机器先被置于程序在该处的状态（单位、坐标系、主轴及其转速、进给、位置），在安全高度上，然后执行其余部分。如果无法推算出该状态（例如在 `G53` 或 `G92` 之后），则会拒绝执行。
* **检查程序**（**Check the program**，*机器* 菜单，或 **点动** 页面上的 *每次运行前检查程序*（*Check the program before every run*））：控制器以检查模式（`$C`）运行程序。不会有任何运动，无法理解的行会连同其行号一起报告。开启该选项时，只有在检查没有发现问题时才会开始真正的任务。
* **暂停：** 当程序到达换刀处时，机器会在那里停下（前一行已执行完），并弹出一个窗口说明要装入哪把刀具。**探测 Z**（**Probe Z**）用对刀板重新设定 Z；**继续任务**（**Continue the job**）继续执行，**停止任务**（**Stop the job**）结束任务。任务等待期间，你可以在控制标签页上点动、归零和探测。
* 任务期间出现的错误和报警会被计数，并记住每种的第一行。

## 机器菜单

* **固件设置 ($$)**（**Firmware settings ($$)**）：控制器的设置，带搜索功能和一个只显示与典型值不同的设置的筛选器。更改会在询问后写入；之后会重新读取设置。**每次会话的第一次更改会把所有设置保存到一个文件中**，位于数据文件夹（`firmware-backups`）中。**备份到文件…**（**Back up to a file…**）和 **从文件恢复…**（**Restore from a file…**）手动执行此操作（在写入任何内容之前会把文件与控制器进行比较，之后再读回）；**恢复出厂设置 ($RST=$)…**（**Factory settings ($RST=$)…**）需要输入单词 RESET。
* **校准**（**Calibration**）：*每毫米步数*（*steps per millimetre*，要求移动一段距离，测量它，得到新的 `$100` / `$101` / `$102` 并写入）和 *各轴的垂直度*（*squareness of the axes*，输入一个矩形的两条对角线：会显示角度和偏移量）。
* **诊断与统计**（**Diagnostics and statistics**）：控制器的输入引脚（限位开关、探针、门、保持、复位、启动）、固件、该机器的任务、运行时间、报警和错误，以及 **维护提醒**（**maintenance reminders**，例如“每 50 小时给导轨上油”；在 **维护**（**Maintenance**）页面中设置）。**导出诊断信息 (zip)…**（**Export diagnostics (zip)…**）保存报告、设置、控制台和程序。

## 对刀仪（MillCreator）

每把刀具的刀尖都会触碰的传感器，可以让新刀具获得与前一把完全相同的 Z，而无需再次触碰工件。菜单 **机器 → 对刀仪…**（**Machine → Tool length sensor…**）会引导你完成以下步骤：

1. **传感器的位置：** 让机器回原点，把刀具点动到传感器中心上方几毫米处，然后按 **传感器在这里**（**The sensor is here**）。位置以 *机器* 坐标保存，因此切勿移动传感器。同一窗口中还有移动高度、失败距离、回退距离和两种速度。
2. **第一把刀具，即基准：** 装入第一把刀具并用它在工件上设定 Z（探测 Z，或触碰表面后按 Z0）。**测量基准刀具**（**Measure the reference tool**）把刀具移到传感器上并触碰两次（先快速，后退，再慢速）；触碰时的 Z 随设备保存。
3. **其他每把刀具：** 当任务因换刀而暂停时，窗口中有 **测量刀具（传感器）**（**Measure the tool (sensor)**）：触碰后，Z 会被设定为使该位置具有基准刀具的 Z，然后刀具上升。也可以在向导中手动执行相同操作（**测量此刀具并设定 Z**（**Measure this tool and set Z**）），**仅测量**（**Only measure**）显示刀具长了或短了多少，而不改变任何内容。

控制器的探针输入必须接到传感器上。当该输入已经闭合、机器不处于空闲状态，或在控制器报告其位置之前，测量会被拒绝。**尚未在真实机器上试用：** 第一次使用时，请把手放在停止按钮附近。

## 控制器设置的副本

每台设备都会保存其控制器设置（`$$`）的副本。第一次连接机器时会创建一份，之后每当连接时读取的设置与最新副本不同时都会再创建一份：状态栏和控制台会说明有多少项设置发生了变化以及是哪些（`$110: 3000 → 5000`），这样你就能注意到从其他程序或由控制器本身所做的更改。在这里所做的更改（在 **固件设置** 中写入）会获得自己的副本，而不会发出警报。固件设置窗口中的 **立即创建副本**（**Make a copy now**）以及设备设置 **机器** 页面中的同名按钮可以手动创建副本；**恢复…**（**Restore…**）把副本与控制器进行比较，并在询问后写回差异；**删除**（**Delete**）移除一份副本。保留最新的八份。副本是设备的一部分，因此会包含在 **程序的备份** 和导出的设备文件中。

## 控制台

**控制台**（**Console**）标签页显示发送到控制器的内容（`>`）和返回的内容（`<`），以及程序的消息（`#`）。在其字段中输入的 **你自己的命令** 有单独的颜色，因此与程序发送的内容区分开来。在该字段中，**Up** 和 **Down** 键浏览你从该字段发送过的命令（仅限这些命令）；你正在输入的内容会在末尾重新出现。该列表一直保留到程序关闭。**设置 → 视图选项… → G-code 控制台**（**Settings → View options… → G-code console**）设置字体大小和颜色。

## 报警和错误

**GRBL 版本。** 在设备连接页面的 *GRBL 版本*（*GRBL version*）下选择主板的版本：**1.1 或更新**（**1.1 or newer**，默认；也适用于 grblHAL 和 FluidNC）、**1.0**、**0.9**、**0.8** 或 **0.7 或更旧**（**0.7 or older**）。GRBL 0.8、0.9 和 1.0 以 `<Idle,MPos:…,WPos:…>` 报告位置，并且没有 `$J=` 点动命令，因此程序使用普通的 `G91` / `G1` 移动进行点动；这样的点动无法中途取消，会一直运行到其步长结束。GRBL 0.7 完全没有实时命令：没有状态报告（因此没有位置）、没有暂停、继续、回原点或解锁，停止只会丢弃尚未发送的行，而主板会执行完已经收到的内容；该固件还会截断超过 49 个字符的行。主轴（`M3 S…`）在所有版本中的工作方式相同。

当 GRBL 报告 `ALARM:n` 或 `error:n` 时，控制台会在其下方添加一行解释，状态栏也会显示它。这些解释提供程序的全部 38 种语言版本。

> ⚠️ 探测、点动和暂停都会发送真实的运动。请让停止按钮保持在伸手可及的范围内。

## 当机器停止时

报警、任务中的错误或控制器没有响应时，会在 **屏幕中央打开一个窗口**：说明发生了什么，并有两个大按钮，**停止**（**STOP**，红色：停止任务和主轴）和 **解锁**（**UNLOCK**，橙色：清除报警，`$X`）。在解锁之前请先查看停止的原因：刀具可能还在材料中。

## 其他控制器：Smoothieware、Duet 和 LinuxCNC

* **Smoothieware：** 连接页面的 **GRBL 版本** 列表中，在各 GRBL 版本旁边有 **Smoothieware（非 GRBL）**（**Smoothieware (not GRBL)**）。该主板通过与 GRBL 相同的层进行流式传输；它没有 `$` 设置，因此固件页面不适用。控制标签页上并非每个按钮都适用于它。
* **通过 HTTP 连接的 Duet / RepRapFirmware：** 在连接页面上勾选 **Duet / RepRapFirmware (HTTP)**，并给出主板的 **地址**（**address**）（以及其 **密码**（**password**），密码不会被保存）。这样控制标签页上会有 **发送并开始**（**Send and start**，程序被上传到 `0:/gcodes/` 并用 `M32` 启动）、**状态**（**State**，空闲、打印中……以及文件的进度）和 **停止**（**Stop**）。主板自行运行文件，因此没有点动、没有倍率调整，也没有流式传输。它适用于独立模式下的 RepRapFirmware 2 和 3；由单板计算机驱动的 Duet（SBC 模式）不在支持范围内。
* **LinuxCNC（文件）：** 添加设备时选择 **LinuxCNC（文件）**（**LinuxCNC (file)**）作为控制器（或在连接页面上勾选）。LinuxCNC 自行运行程序，因此没有连接：**开始** 会保存 G-code 文件（与 **保存 G-code**（**Save G-code**）相同），供你在 LinuxCNC 中打开。G-code 是程序的普通 G-code（没有 `$` 命令，以 `M30` 结尾）。尚未在真实机器上试用。
