# 图层与操作

一个项目有 **64 个图层**。每个图形都位于一个图层上，由图层决定对它执行什么操作。在 **图层**（**Layers**）标签页中单击一个图层，使其成为当前图层（新图形会放到该图层上），并在列表下方编辑它。

![图层](https://raw.githubusercontent.com/michalsarna/MillCreator/main/docs/screenshots/05-layers.png)

在列表中：勾选框决定图层是否参与刀具路径和 G-code，眼睛图标决定是否在工作区中显示它，数字表示其上有多少个图形。

### 图片

放到图层上的图片会把该图层切换为 **图片**（**Picture**）操作（只切换一次；你可以改回去）。然后该图层按 **图片方式**（**Picture method**）以其 **深度**（**Depth**）一次雕刻出图片（请使用较浅的深度：行和点的数量很多）：**抖动行**（**Dithered rows**，图片经过抖动处理，每一行在暗处切削）、**点**（**Dots**，每个暗色单元一个孔）、**按色调定深度**（**Depth by tone**，以随色调变化的深度切削各行：越暗越深，最深到图层的深度）或 **3D 浮雕**（**3D relief**）。对于前两种，需要选择 **抖动算法**（**Dithering**：阈值、Floyd–Steinberg、Jarvis、Stucki、Atkinson、有序）。各行之间的距离为刀具的 **步距**（**Step over**，其直径的百分比），并按 **扫描角度**（**Scan angle**）运行。

**3D 浮雕**（与 molino 中相同）：每个像素的灰度就是一个深度，黑色最深，白色不切削，最深到图层的 **深度**。浮雕按 **每层切深**（**Pass depth**）分层切削到全深（最后一层就是浮雕本身），各行之间相隔 **步距**，并且 **会考虑刀具的形状**（平底刀、球头刀、牛鼻刀或 V 形刀在其刀体下方的任何位置都不会切入浮雕：刀具放不进去的窄坑会保持较浅；在图片边缘附近，刀具会保持稍高的位置）。请先调整图片（亮度、对比度、负片）：*排列 → 调整图片…*（*Arrange → Adjust image…*）。**铣削 → 将浮雕导出为 STL…**（**Milling → Export relief as STL…**）把雕刻好的工件保存为封闭实体（厚度取材料标签页中的材料厚度），以便查看或分享。

浮雕可以像实际任务那样分两个图层切削：图层的 **浮雕部分**（**Relief part**）可以是 **粗加工和精加工**（**Rough and finish**，一直以来的做法）、**粗加工**（**Rough**，分层切到浮雕，并在其上留下 *预留余量*（*Stock to leave*）；使用平底刀）或 **精加工**（**Finish**，在浮雕本身上走一遍，按 *步距* 和 *扫描角度* 逐行进行；使用球头刀）。把同一张图片放到两个图层上（或复制图层），给第一个图层一把平底刀并选择粗加工，给第二个图层一把球头刀并选择精加工；各图层按其顺序加工。

**文件 → 导入 → 将 3D 模型导入为浮雕…**（**File → Import → Import 3D model as relief…**，也可以用打开以及拖放）读取以毫米为单位的 **STL**（二进制或文本）、**OBJ** 或 **3MF** 模型，从上方观察它，并把深度图作为图片放到页面上：模型的最高点为白色（不切削），最低点为黑色，模型没有内容的地方深度图为黑色（周围的材料会被清除）。图片与模型一样大。程序会把它放到已经在切削浮雕的图层上，或者把第一个空图层切换为使用 3D 浮雕方式的图片操作，并使用刀具库中的一把球头刀和模型的深度（最多为材料的厚度）。可以读取最多含五百万个三角形的模型；3MF 的组件和变换不会被应用（每个对象按其在文件中的样子放置）。如果你想切削模型的背面，请先在其所属程序中把模型翻转过来。

同一图层上的其他图形会作为线条被跟随加工。在使用其他操作的图层上，图片只会显示（会有警告说明它不会被铣削）。

## 图层的设置
| 设置 | 含义 |
|---|---|
| 名称、颜色 | 自由设置；颜色是其图形的颜色，也是其在 3D 视图中切削的颜色 |
| 操作（Operation） | 见下文 |
| 刀具（Bit） | [刀具库](Bit-Library-ZH)中的任何一把刀具。选择刀具时会采用其进给、下刀进给、主轴转速、等于其直径一半的每层切深以及步距 |
| 深度（Depth） | 从材料顶面往下的总深度 |
| 面（Side） | **顶面**（**Top**）或 **底面（翻转后）**（**Bottom (turned over)**）：双面任务（参见[材料](Material-ZH)）。底面按从顶面透过材料看到的样子绘制；切削时会被翻转 |
| 每层切深（Pass depth） | 一次走刀的深度；最后一层总是止于全深。**0 表示一次切到全深**（当这比刀具的切削刃部分更深时会有警告）；刀具库中刀具的 *每层切深（占直径比例）*（*Pass depth (of the diameter)*）也是如此 |
| 步距（Step over） | 对于型腔：各环之间的距离，以直径的比例表示 |
| 进给、下刀进给（Feed, plunge feed） | 在材料中以及下刀时的 mm/min |
| 主轴转速（Spindle speed） | rpm；超出设备范围的值会被报告 |
| 方向（Direction） | 对于轮廓或型腔：**按绘制方向**（**As drawn**，程序一直以来的做法）、**顺铣**（**Climb**）或 **逆铣**（**Conventional**）。主轴顺时针旋转时，顺铣使材料保持在刀具左侧（绕零件逆时针，在型腔中顺时针）；零件上孔的环则反方向运行 |
| 预留余量、精加工走刀（Stock to leave, Finishing pass） | 切到深度的各层走刀与线条保持这一距离；启用 *精加工走刀* 时，会在全深处沿真实线条再走一刀，去除余量 |
| 切入、切出、重叠（Lead in, Lead out, Overlap） | 对于轮廓（外侧和内侧）：刀具从废料一侧切入线条，并以同样方式离开，因此下刀的痕迹不会留在零件上。**直线**（**Line**，以 *切入角度*（*Lead angle*）进入的直线，90° 为垂直于线条）或 **圆弧**（**Arc**，与线条相切的四分之一圆，半径为 *切入半径*（*Lead radius*））；*切入长度*（*Lead length*）/ *切入半径* 为其尺寸。废料位于零件的外侧、孔的内侧以及内侧轮廓的内侧。从转角开始的环会改为从其最长边的中点开始。会穿过线条或伸入该图层另一个环的切入会被缩小一半或四分之一，或者省略，并给出警告。*重叠* 在切出之前越过起点继续走一段。使用切入切出时，刀具在每个深度都在切入起点（位于废料中）以下刀进给垂直下刀；这些环不使用 *进刀方式*（*Entry*）。预览、3D 视图和时间都会显示切入切出 |
| 进刀方式（Entry） | 刀具如何下刀：**垂直下刀**（**Plunge**，以下刀进给垂直向下）、**之字形斜坡**（**Zigzag ramp**，沿路径的第一段来回移动）、**沿轮廓斜坡**（**Ramp along the contour**，边绕行边下降）或 **螺旋**（**Helix**，在型腔中沿一个放得下的圆；否则使用沿轮廓斜坡）。**斜坡角度**（**Ramp angle**）是以度为单位的坡度；**斜坡进给**（**Ramp feed**）是斜坡上的进给（0 = 使用刀具库中该刀具的 *斜坡进给*，否则使用下刀进给）。陡于 45° 的斜坡会被报告 |
| 型腔样式、光栅角度（Pocket pattern, Raster angle） | 对于型腔和平面铣：**环形**（**Rings**，从外向内一环接一环；当宽度不是步距的整数倍时，沿中间走一环以清除剩下的窄条）或 **光栅**（**Raster**，按 *光栅角度* 来回走的平行线，当线与线之间的路径保持在区域内部时会连接起来） |
| 环与环之间不抬刀（Stay down between rings） | 对于样式为 *环形* 的 *型腔*（默认关闭）：在每个深度上各环依次进行，当整个路径都位于刀具可到达的区域内时，刀具通过在材料中切削移动到下一环，而不是抬起（绝不会穿过岛屿，因此在那里刀具仍像以前一样抬起）。更深一层的第一个环从上一层的深度进入。预览和时间估算会显示这些新的移动。 |
| 轮廓走刀（Outline pass） | 对于型腔：在每个深度上，于清除 **之前**（**Before**）或 **之后**（**After**）沿侧壁走一刀（或 *无*（*None*）） |
| 残料图层（Rest of layer） | 对于型腔：只清除另一个图层（使用更大刀具的型腔）的刀具无法到达的部分，使用本图层的刀具，该刀具必须更小 |
| 起始深度、镶嵌、镶嵌间隙（Start depth, Inlay, Inlay gap） | 用于 **V 雕**（**V-carve**）。*镶嵌* 制作镶嵌件的一半：**凹件**（**Socket**）雕刻在图形内部（按 *镶嵌间隙* 放大），**凸件**（**Plug**）是按间隙缩小的图形，倾斜的侧壁雕刻在其 *周围*，即线条外侧，直到图层的深度。在第二块材料上用翻转（镜像）的相同图形雕刻凸件，用轮廓图层将其切出，然后粘入凹件 |
| 浮雕部分（Relief part） | 用于 **3D 浮雕**：粗加工和精加工、粗加工（带 *预留余量*）或精加工，参见上文的图片。精加工可以作为另一个使用更大刀具的精加工图层的 **残料图层**：此时较小的球头刀只去较大刀具无法到达的地方（窄槽、尖角，在其半径范围内），这样可以节省第二次完整精加工的大部分时间；其刀具必须更小（警告） |
| 照片 V 雕（Photo V-carve） | **图片** 操作的一种图片方式，与 PhotoVCarve 的做法相同：横跨图片的线条，以 **扫描角度** 相隔 **线间距**（**Line spacing**），每条线用 V 形刀切削，其深度使沟槽宽度与该处图片的暗度相当。黑色切到使沟槽宽度等于线间距的深度（各线相接），白色不切削；图层深度只起限制作用。沿线条每隔线间距的六分之一读取一次图片。浅色、细纹理的木材（枫木）和 60° V 形刀可获得最佳对比度；亮度和对比度在图片的窗口中设置。使用平底刀或球头刀会有警告。 |
| 素描雕刻（Sketch carving） | **图片** 操作的一种图片方式：用某种 **风格**（**Style**，风格描摹的风格：蚀刻、等高线、波浪线、螺旋……，间距为刀具的步距）把图片重新绘制为线条，每条线用 V 形刀雕刻，图片越暗处越深，因而越宽，最深到图层的深度；在接近白色的地方刀具会抬起。看起来像铅笔素描 |
| 冷却液、吸尘器（Coolant, Dust collector） | 切削该图层时，*冷却液* 为关闭、雾化（M7）或喷淋（M8）；*吸尘器* 用设备自己的代码行开启（设备设置 → G-code：*吸尘器开启 / 关闭*；图层要求使用吸尘器但没有代码行时会被报告）。在要求相同设置的图层之间它们保持开启，在换刀之前和程序结束时关闭 |
| 摆线（Trochoids） | 用于“沿线加工”：刀具沿线条以环形移动（*摆线直径*（*Trochoid diameter*），每转前进 *摆线步长*（*Trochoid step*）；*半圆*（*Half circles*）则改为横跨线条摆动），从而以较轻的负荷切出与环和刀具一样宽的槽 |
| 连接桥（Tabs） | **完整**（**Full**，刀具升到材料上方）、**部分**（**Partial**，升到连接桥的高度）或 **斜坡**（**Ramp**，带斜坡的部分连接桥，*连接桥坡度*（*Tab slope*））；*连接桥宽度*（*Tab width*）是连接桥在零件处的宽度（另加刀具宽度），*连接桥高度*（*Tab height*）从切削底部量起。它们均匀分布：环上每隔 *连接桥间距*（*Tab spacing*）一个，数量在给定的最少和最多之间；开启 *孔上不加连接桥*（*No tabs on holes*）时，零件上的孔没有连接桥。只有低于连接桥顶部的走刀会被抬高。适用于轮廓以及闭合线条上的“沿线加工”。**手动放置连接桥**（**Place tabs by hand**，位于连接桥设置下方）把工作区变成该图层图形的连接桥编辑器：在轮廓上单击添加一个连接桥（黄色圆点），沿轮廓拖动圆点可移动它，单击圆点可移除它；*清除手动放置的连接桥*（*Clear hand-placed tabs*）会全部移除。手动放置了连接桥的环只使用这些连接桥；它们随图层保存在项目中，并在图形移动或缩放时跟随图形 |

## 连接桥分步说明

连接桥（桥接）是留在轮廓上的薄薄的材料，使切出的零件一直保持在原位直到最后，不会在刀具下移动。

1. 把零件放到切出它的图层上：**沿线外侧切割**（**Cut outside the line**）（对于孔为 **沿线内侧切割**（**Cut inside the line**），闭合线条上的 **沿线加工**（**Follow the line**））。其他操作没有连接桥。
2. 在 **图层** 标签页上选择该图层，并打开其设置中的 **连接桥 / 桥接**（**Tabs / bridges**）部分。
3. 勾选 **连接桥**（**Tabs**）。程序会在该图层的每条轮廓上均匀分布它们。
4. 设置它们：
   * **连接桥类型**（**Tab type**）：**完整**（**Full**，在连接桥处刀具升到材料上方）、**部分**（**Partial**，刀具升到连接桥的高度）或 **斜坡**（**Ramp**，部分连接桥，带斜坡；角度为 **连接桥坡度**（**Tab slope**））。
   * **连接桥宽度**（**Tab width**）：连接桥在零件处的宽度（另加刀具宽度）。
   * **连接桥高度**（**Tab height**）：从切削底部量起。只有低于连接桥顶部的走刀会被抬高。与切削一样高的连接桥起不到任何固定作用：程序会对此发出警告。
   * **连接桥间距**（**Tab spacing**）：轮廓每隔多少毫米一个连接桥，以及一条轮廓上的 **最少和最多连接桥数**（**Fewest and most tabs**）。
   * **孔上不加连接桥**（**No tabs on holes**）：零件内部的孔不加连接桥。
5. 在预览中检查它们（3D 视图和 G-code 会显示被抬高的移动）。

**在你选择的位置：** 在连接桥设置下方按 **手动放置连接桥**（**Place tabs by hand**）（或 **铣削 → 手动放置连接桥**（**Milling → Place tabs by hand**））。工作区会变成该图层图形的连接桥编辑器：在轮廓上单击添加一个连接桥（黄色圆点），沿轮廓拖动圆点可移动它，单击圆点可移除它。再次按该按钮结束。手动放置了连接桥的轮廓只使用这些连接桥；其他轮廓仍使用均匀分布的连接桥。连接桥保存在项目中，并在图形移动或缩放时跟随图形。**清除手动放置的连接桥**（**Clear hand-placed tabs**）会全部移除。

任务完成后，用刀或锯切断连接桥，并把剩余部分打磨平整。

## 操作
| 操作 | 刀具的动作 |
|---|---|
| **沿线外侧切割**（**Cut outside the line**） | 沿线条外侧绕行，因此图形保留下来：从材料中切出一个零件 |
| **沿线内侧切割**（**Cut inside the line**） | 沿线条内侧绕行，因此图形掉落：形成一个孔或窗口 |
| **沿线加工**（**Follow the line**） | 刀具中心沿线条移动（雕刻、凹槽）；开放线条也可以；在更深的走刀中，刀具沿线条返回 |
| **型腔**（**Pocket**） | 从外向内一环接一环，清除线条内部的全部区域 |
| **钻孔**（**Drill**） | 在每个闭合图形的中心钻一个孔，按每层切深分段啄钻 |
| **图片**（**Picture**） | 雕刻图层上的图片（参见上文的图片） |
| **平面铣**（**Face**） | 在该图层所有图形的外框范围内铣平材料顶面（绘制一个矩形来给出尺寸），按环形或光栅方式；*悬出量*（*Overhang*）是刀具边缘超出外框边缘的距离（刀具稍微超出一点，以免留下凸棱） |
| **镗孔**（**Bore**） | 比刀具更大的圆孔：刀具沿圆孔以螺旋方式下降（沿轮廓斜坡，按 *斜坡角度*），然后在全深处绕一圈；中间的芯料掉落 |
| **倒角**（**Chamfer**） | V 形刀（或雕刻刀）沿线条以一定深度移动，使表面上的倒角宽度为 *倒角宽度*（*Chamfer width*）（图层的深度由它决定；使用平底刀会被报告） |
| **V 雕**（**V-carve**） | V 形刀（或雕刻刀）离图形边缘越远就切得越深，因此侧壁倾斜，转角清晰锐利：文字、标牌、镶嵌。*深度* 是刀具的最大深度；在图形宽于此值的地方，底部是平的（由 V 形刀本身切削，会留下凸棱且耗时较长，因此程序会给出提示：在 *型腔* 图层中使用平底刀效果更好）。*起始深度*（*Start depth*）：比此值更浅的部分不切削（侧壁的浅层部分无论如何都会被更深的环切到，因此这只是节省时间）。使用平底刀会被报告 |
| **狗骨槽**（**Dogbone slot**） | 与 *沿线内侧切割* 相同，但在每个尖角处开一个槽口：刀具中心继续前进，直到其边缘到达转角，使方形零件能装进由圆形刀具铣出的槽中 |
| **拖刀**（**Drag knife**） | 装在刀座中的拖刀沿线条切割，主轴保持静止，以图层的深度一次切完；会补偿刀尖偏移，并先切孔。任务在该图层之前暂停以装入拖刀。参见[拖刀](Drag-Knife-ZH) |
| **螺纹铣**（**Thread mill**） | 螺纹铣刀沿该图层的每个圆以螺旋方式移动，每圈一个 *螺距*（*Pitch*），直到图层的深度。**螺纹**（**Thread**）：**内螺纹（螺母）**（**Inside (a nut)**）或 **外螺纹（螺钉）**（**Outside (a screw)**）；两种情况下都绘制螺钉外径的圆。对于螺母，先把孔钻或镗到大约直径减去 1.08 × 螺距；对于螺钉，先把凸台切到外径。**常用规格**（**Usual size**）采用 ISO 公制（M3 … M30）或 UNC / UNF 螺钉的螺距；螺纹深度按 ISO 标准（螺母为尖 V 的 5/8，螺钉为 17/24）。**径向走刀**（**Radial passes**）把该深度分几次切完。刀具始终顺铣：在孔内逆时针，绕凸台顺时针；右旋螺纹在孔内向上、绕凸台向下，**左旋螺纹**（**Left-hand thread**）则相反。在孔内，刀具在孔的中心下降；绕凸台时，刀具在其外侧 1 mm 处等待。请使用螺纹铣刀（其直径在刀具库中）；对于钻好的孔而言过大的刀具会省略该螺纹并给出警告，不是圆形的图形会得到警告（螺纹绕其中心进行） |
| **开槽**（**Fluting**） | 沿每条线条的凹槽，从表面斜坡下降，在图层深度处运行，然后再斜坡上升（**斜坡**（**Ramps**）：两端、起点、终点；**斜坡长度**（**Ramp length**）为线条长度的百分比）；按每层切深分层进行。柱子的凹槽、装饰槽；请使用球头刀或 V 形刀 |
| **线脚**（**Moulding**） | 沿每条线条扫掠一个 **截面**（**Profile**：圆角（Roundover）、凹圆（Cove）、S 形（Ogee）、斜面（Slope）、半圆槽（Half round groove）），宽度为 *宽度*（*Width*），深度与图层相同，以步距并排分多道走刀，每道的深度为该处截面的深度，并考虑刀具的形状（绝不会切到截面以下）。截面位于线条方向的左侧（半圆槽以线条为中心）：板材的边缘、画框。请使用球头刀 |
| **纹理**（**Texture**） | 用球头刀以行（*行角度*（*Angle of the rows*），相隔步距）铲出短凹痕，覆盖闭合图形的内部：*笔画长度*（*Stroke length*）、*笔画间隙*（*Gap between strokes*）、其长度和深度的 *变化*（*Variation*），以及 *图案编号*（*Pattern number*，相同的编号得到相同的笔画）。图层的深度是最深的凹痕 |
| **3D 形状**（**3D shape**） | 图层上的每个闭合图形都成为一个 3D 形体：**形体**（**Form**）为圆顶（Dome，从边缘到图形中心的四分之一圆）、斜面（Slope，在 *斜面宽度*（*Width of the slope*）上的直斜面：棱锥或斜边）或平顶（Flat top，直壁），**凸起**（**Raised**）于材料（其外框稍宽一些，被切到图层的深度）或 **下沉**（**Sunk**）于材料中（只切削图形内部）。图形中的孔保持低位。它像浮雕一样切削（**浮雕部分**：粗加工、精加工或两者，各行间距为刀具的步距），并考虑刀具的形状 |

同一图层的图形构成一个区域（奇偶规则）：位于另一个图形内部的图形是该图形的孔。应分别切削的图形请放在不同的图层上。开放线条不参与轮廓和型腔加工（程序会给出提示）。图片只在使用 **图片** 操作的图层上被铣削；在其他图层上只会显示。

## 检查的内容
没有刀具的图层、超过材料厚度的深度、超过机器行程的深度、超出范围的主轴转速、超出工作区的切削以及对刀具而言过小的线条，都会在预览中以及写入 G-code 时作为警告报告。

## 切削速度和每齿进给

图层（以及刀具库中刀具的 *初始速度*（*Starting speeds*））在主轴转速和进给旁边显示 **切削速度 (Vc)**（**Cutting speed (Vc)**，m/min，Vc = π · D · n / 1000）、**每齿进给 (fz)**（**Feed per tooth (fz)**，mm，fz = F / (n · z)）和 **每齿下刀量**（**Plunge per tooth**），根据刀具的直径 D 和刃数 z 计算。输入 Vc 会改变主轴转速，输入 fz 会改变进给（或下刀进给）；只保存主轴转速和以 mm/min 为单位的进给，因此文件不会改变。没有刀具时这些行显示为灰色（提示会说明原因：*来自刀具：直径和刃数*（*From the bit: the diameter and the number of flutes*））。

## 图层预设

在图层设置的上方：**保存预设…**（**Save preset…**）和 **加载预设**（**Load preset**）打开 **图层预设**（**Layer presets**）窗口：一个名称字段和 **保存预设…** 以该名称保存图层的切削方式（操作、刀具、深度、速度、连接桥、斜坡……）（同名的预设会被替换）；搜索字段用于缩小列表；单击预设会把它应用到图层上，铅笔图标用于重命名，× 用于删除；**导出…**（**Export…**）把所有预设写入文件，**导入…**（**Import…**）添加文件中的预设（有问题的条目会被略去）。图层的名称、颜色和顺序、残料型腔所承接的图层以及手动放置的连接桥保持不变。如果预设的刀具已不在刀具库中，则会把其他设置应用到图层上，并使图层没有刀具（状态行会给出提示）。预设保存在共享数据文件夹中的 `mill_layer_presets.json` 中（最多 60 个）。
