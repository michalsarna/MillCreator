# 快速入门

从头开始完成第一个任务：设备、材料、一个图形、带刀具的图层、在 3D 和 G-code 中查看任务，以及给机器用的文件。**粗体** 标签是程序中的名称；在 macOS 上 Ctrl 即 Cmd。

## 1. 设备

启动界面在 **设备**（**Device**）下列出你的机器。选择你要使用的那一台。

* **添加设备…**（**Add device…**）会打开一个包含基本设置的窗口，与 LightCreator 和 PenCreator 中的相同：**名称**（**Name**）、**控制器**（**Controller**，某个 GRBL 版本、Duet 或 LinuxCNC）、连接以及 **从设备读取**（**Read from device**，工作区、速度和主轴信息来自控制器）、**单位**（**Units**）、**工作区**（**Work area**，X、Y、Z）、**机器零点 (0,0)**（**Machine zero (0,0)**）、**安全高度**（**Safe height**）和 **主轴**（**Spindle**）、可选的摄像头，以及 **值得检查**（**Worth checking**）。**添加设备**（**Add device**）保存设备；**更多设置…**（**More settings…**）会带着已输入的内容打开完整的设备窗口（所有页面见[设备与摄像头](Devices-and-Cameras-ZH)），在那里新设备也可以从 **起点 → 常见机器尺寸…**（**Start from → A usual machine size…**）开始。
* **编辑…**（**Edit…**）、**复制**（**Duplicate**）和 **导入…**（**Import…**）用于修改、复制设备或从文件读取设备。
* 如果没有机器，请按 **我没有设备**（**I have no device**）：程序会创建并选中一个名为 *Dummy* 的替代设备（工作区 300 × 200 mm，Z 向 60 mm，安全高度 5 mm，主轴 1000–24000 rpm）。在完全没有设备时使用 **新建**（**New**）或 **打开…**（**Open…**）也会创建并使用它。

然后按 **新建**（**New**）（或对已有文件按 **打开…**；**最近打开**（**Open recent**）列出最近的文件）。

## 2. 项目设置

按 **新建** 后，**项目设置**（**Project setup**）窗口会询问材料块的情况（也可以从 **文件 → 项目设置…**（**File → Project setup…**）再次打开）：

| 字段 | 含义 |
|---|---|
| **材料宽度**（**Material width**）、**材料高度**（**Material height**） | 材料块的尺寸（初始为工作区大小，最大 300 × 200 mm）。 |
| **厚度**（**Thickness**） | 材料块的厚度（0.1 至 500 mm）。 |
| **程序零点**（**Zero of the program**） | X 0、Y 0 在材料块上的位置：**左前**（**Front left**）、**右前**（**Front right**）、**左后**（**Back left**）、**右后**（**Back right**）或 **中心**（**Centre**）。 |
| **Z 从材料底部算起**（**Z counts from the bottom of the material**） | 关闭：Z = 0 为材料顶面。开启：每个 Z 都是相对于材料底面的高度。 |
| **工作区即材料**（**Work area is the material**） | 使设备的工作区与材料块一样大。 |

材料位于页面的左上方。**应用**（**Apply**）会为工件坐标系 **G54**（或设备中选择的坐标系）编写程序，其零点位于你选择的位置：请在机器上把该零点设在材料块的对应位置（点动到那里，然后在 **控制**（**Control**）标签页上按 **X0**、**Y0** 和 **Z0** 或 **全部归零**（**Zero all**），或者使用探测）。绿色的 **应用** 和蓝色的 **跳过**（**Skip**）位于窗口底部。对新项目按 **跳过**（或关闭窗口）会把设备和项目的零点留在一侧，并使材料与机器的工作区一样大。这些选择会随项目一起保存。

**材料形状 → 圆柱（旋转轴）**（**Shape of the material → Cylinder (rotary)**）用于装在旋转附件上的圆形工件：输入其 **工件直径**（**Workpiece diameter**）和 **工件长度**（**Workpiece length**），窗口会显示卡盘中的圆柱及其尺寸、Y 绕圆柱的旋转方向以及其表面上的零点。**应用** 会以该直径开启设备的旋转附件（该设置随设备保存）；此时材料就是展开后的表面——长度沿 X，圆周（π × 直径）沿 Y——Z 从表面顶部算起，最深的切削为半径。工作区在每一圈处显示一条蓝线。再次选择 **块料**（**Block**）会关闭旋转轴。

**双面任务**（**Two-sided job**，块料）：A 面和 B 面成为项目的两个工作区，工作区上方有一个 **A 面 / B 面**（**Side A / Side B**）切换开关。选择材料的 **翻转轴线**（**Turned over round**）：**H**（水平轴：前后互换）或 **V**（垂直轴：左右互换），以及是否添加 **对位标记**（**Alignment marks**，在翻转线上的两个定位销孔，在 A 面上钻通）。B 面按材料翻转后的摆放方式绘制，并按绘制的样子切削；每一面都会以淡色虚线 **幽灵**（**ghosts**）显示另一面翻转后的图形，这些图形无法选中（**另一面的幽灵**（**Ghosts of the other side**）用于开关它们）。显示 B 面也会使其成为被切削的一面。

## 3. 材料

**材料**（**Material**）标签页：**工件材料**（**Material of the workpiece**）（**浅色木材**（**Wood, light**）、**中色木材**（**Wood, medium**）、**深色木材**（**Wood, dark**）、**金属**（**Metal**）、可自选 **颜色**（**Colour**）的 **塑料**（**Plastic**））和 **厚度**（**Thickness**）。颜色仅用于 3D 视图；进给来自刀具和图层。**首次加工**（**First pass**）可以让每个图层先沿边缘进行一次浅切。参见[材料](Material-ZH)。

## 4. 图形

* 使用左侧的工具绘制：**矩形 (R)**（**Rectangle (R)**）、**椭圆 (E)**（**Ellipse (E)**）、**多边形 (G)**（**Polygon (G)**）、**文本 (T)**（**Text (T)**）、**折线 / 钢笔 (P)**（**Polyline / pen (P)**）……（字母即快捷键；**插入**（**Insert**）菜单中也有相同的工具）。新图形会放在当前图层上。
* 或者导入一个：**文件 → 打开…**（**File → Open…**，SVG、PDF、Illustrator、DXF），**文件 → 导入 ▸**（**File → Import ▸**，图片、DXF、LightBurn 项目、UGS 设计、作为浮雕的 3D 模型），**剪贴画**（**Clipart**）标签页，或把文件拖放到窗口上。
* **属性**（**Properties**）标签页设置所选对象的位置和尺寸。参见[设计工具](Design-Tools-ZH)。

## 5. 图层：操作、刀具、深度、进给

图形按其所在图层的设置进行铣削。打开 **图层**（**Layers**）标签页。新项目的前几个图层已经准备好：

| 图层 | 操作 | 深度 | 刀具 |
|---|---|---|---|
| *切出*（*Cut out*） | **沿线外侧切割**（**Cut outside the line**，零件保留） | 10 mm | 平底刀 3.175 mm（1/8"） |
| *孔和窗口*（*Holes and windows*） | **沿线内侧切割**（**Cut inside the line**，内部掉落） | 10 mm | 平底刀 3.175 mm（1/8"） |
| *型腔*（*Pocket*） | **型腔**（**Pocket**，区域被清除） | 3 mm | 平底刀 3.175 mm（1/8"） |
| *雕刻*（*Engrave*） | **沿线加工**（**Follow the line**） | 1 mm | V 形刀 60° |
| *钻孔*（*Drill*） | **钻孔**（**Drill**，在每个闭合图形的中心钻一个孔） | 10 mm | 钻头 3 mm |

1. **把图形放到图层上。** 选中图形，在列表中单击图层，然后按 **将所选图形放到此图层**（**Put the selected shapes on this layer**），或在工作区下方的颜色行中单击该图层的颜色（在那里双击会打开该图层的选项）。列表显示含有图形的图层以及当前图层；**显示全部 64 个图层**（**Show all 64 layers**）会显示其余图层。
2. **操作：** **操作**（**Operation**）共有十一种（轮廓、型腔、钻孔、平面铣、镗孔、倒角、V 雕、狗骨槽、图片……）：[图层与操作](Layers-and-Operations-ZH)。
3. **刀具：** 在 **刀具**（**Bit**）中选择。选择刀具时还会根据其初始速度设置 **进给**（**Feed**）、**下刀进给**（**Plunge feed**）、**主轴转速**（**Spindle speed**）、**每层切深**（**Pass depth**）和 **步距**（**Step over**）。**…** 按钮打开 **刀具库**（**Bit library**）（[刀具库](Bit-Library-ZH)）。
4. **深度：** **深度**（**Depth**）是从材料顶面往下的总深度；**每层切深**（**Pass depth**）是一次走刀的深度（0 = 一次切到全深）。设置下方的一行文字会说明这样需要多少层。
5. **进给：** **进给**（**Feed**）和 **下刀进给**（**Plunge feed**）单位为 mm/min，**主轴转速**（**Spindle speed**）单位为 rpm。它们下方根据刀具直径和刃数计算出：**切削速度 (Vc)**（**Cutting speed (Vc)**，m/min）以及 **每齿进给 (fz)**（**Feed per tooth (fz)**）和 **每齿下刀量**（**Plunge per tooth**，mm）。输入 Vc 会改变主轴转速，输入 fz 会改变进给；只保存主轴转速和进给。
6. **连接桥**（**Tabs**）把切出的零件固定在原位：在 *沿线外侧切割* 图层上设置，或手动放置。分步说明：[连接桥分步说明](Layers-and-Operations-ZH#连接桥分步说明)。

列表中的勾选框决定图层是否参与刀具路径和 G-code；眼睛图标用于显示或隐藏图层。好的设置可以用 **保存预设…**（**Save preset…**）保存，并用 **加载预设**（**Load preset**）应用到另一个图层。

## 6. 查看任务

* **刀具路径**（**Toolpaths**，工作区上方的绿色按钮）在图纸上绘制刀具的路径。
* **预览…**（**Preview…**）或 **铣削 → 任务的 3D 视图…**（**Milling → 3D view of the job…**，Ctrl+Shift+P）打开 **预览**（**Preview**）标签页：刻有切削的材料块、在安全高度上的移动、带滑块的动画、切削时间和长度，以及警告（图层没有刀具、比材料更深、超出工作区……）。参见 [3D 视图与 G-code](3D-View-and-G-code-ZH)。
* **预览 G-code**（**Preview G-code**）在一个标签页（*Preview G-code: name.nc*）中以着色方式显示程序本身，不保存任何内容。文本可以编辑；标签页中的 **保存 G-code**（**Save G-code**）写入文件，**重新生成**（**Make again**）从项目重新生成，**分析**（**Analyse**）显示其刀具路径。

## 7. 保存项目和 G-code

* **文件 → 保存**（**File → Save**，Ctrl+S）把项目保存为 `.cre` 文件。
* **保存 G-code**（**Save G-code**，工作区上方的按钮）、**铣削 → 导出 G-code…**（**Milling → Export G-code…**）或 **Ctrl+E** 会询问文件名（`name.nc`）并通过已启用插件的后处理器写入 G-code。启用 **设置 → 视图选项… → 保存后预览 G-code**（**Settings → View options… → Preview G-code after saving**）后，保存的文件会在 G-code 分析中打开。
* **描述**（**Description**）标签页的文本会作为 `(Note: …)` 注释写在 G-code 的开头。

## 8. 在机器上

程序也可以把任务发送到 GRBL 机器（在 TwoTrees TTC450Pro 上测试过，未在其他机器上测试）：

1. 在 **机器 → 设备设置… → 连接**（**Machine → Device settings… → Connection**）中设置端口，然后在 **设备**（**Device**）标签页上按 **连接**（**Connect**）。
2. **回原点**（**Home**），然后点动到程序零点，并在 **控制**（**Control**）标签页上设置它（**X 和 Y 归零**（**Zero X and Y**）、**Z0** 或 **探测 Z**（**Probe Z**））。
3. **边框**（**Frame**）在安全高度、主轴关闭的状态下沿任务的外框走一圈：检查任务是否落在材料上。
4. **开始**（**Start**）发送任务。**停止**（**STOP**）停止任务；**暂停**（**Pause**）和 **继续**（**Resume**）暂停和恢复。**从某行开始…**（**From line…**）从程序的某一行开始。

参见[机器控制](Machine-Control-ZH)。

> ⚠️ 请先在材料上方的空中测试新任务，佩戴护目镜和耳罩，夹紧工件并守在机器旁。参见[安全与限制](Safety-and-Limitations-ZH)。
