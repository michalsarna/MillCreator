# 프로젝트 파일

MillCreator는 LightCreator도 쓰는 baseCreator의 프로젝트 파일인 **`.cre`** 형식으로 저장합니다. 도면, 설명, 그리고 **프로그램마다 하나의 구역**을 담은 JSON 파일 하나입니다. 각 프로그램은 자기 구역을 쓰고 다른 프로그램의 구역은 건드리지 않으므로, 프로젝트가 아무것도 잃지 않고 프로그램 사이를 오갑니다.

MillCreator의 구역 이름은 `mill`입니다. 여기에는 다음이 들어 있습니다.
* 모든 설정(이름, 색, 순서, 작업, 비트, 깊이, 스텝오버, 이송 속도, 스핀들 속도, 방향, 진입 방식, 고정 탭과 손으로 놓은 탭, 절삭유…)을 포함한 **64개 레이어**,
* **재료**(종류, 색, 두께, 첫 패스)와 **프로젝트 설정**(조각의 크기, 조각 위의 프로그램 원점, 바닥 기준 Z),
* **장치의 스냅샷**(이름과 작업 영역),
* 라이브러리에 없는 곳에서도 프로젝트를 열 수 있도록 **레이어가 사용하는 비트**.

LightCreator의 프로젝트(또는 일반 SVG, PDF, LightBurn 파일)를 열면 기본 레이어가 생깁니다. 그 밖의 구역(`laser`)은 보관되었다가 저장할 때 다시 쓰입니다. 프로그램이 아는 것보다 새로운 `mill` 형식의 프로젝트는 메시지와 함께 거부됩니다. 숫자가 잘못된 레이어는 기본값으로 바뀌고, 없는 비트는 **내 비트**(My bits)에 추가됩니다.

장치 자체는 프로젝트에 들어 있지 않고 그 스냅샷만 있습니다. 사용 중인 장치는 시작 화면에서 고른 장치입니다. 스냅샷의 작업 영역이 그 장치의 작업 영역과 다르면 상태 표시줄이 경고합니다.

프로젝트 설명(**설명**(Description) 탭)은 공유 컨테이너의 일부이므로 LightCreator도 같은 텍스트를 보여 줍니다. MillCreator는 이것을 G-code 맨 위에 `(Note: …)` 주석으로도 씁니다([3D 보기와 G-code](3D-View-and-G-code-KO#g-code-내보내기) 참고).
