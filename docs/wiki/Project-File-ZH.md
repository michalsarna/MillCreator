# 项目文件

MillCreator 保存 **`.cre`** 文件，即 baseCreator 的项目文件，LightCreator 也写入这种文件：一个 JSON 文件，包含图纸、描述以及 **每个程序一个部分**。每个程序写入自己的部分，并保持其他程序的部分不变，因此项目可以在程序之间传递而不会丢失任何内容。

MillCreator 的部分名为 `mill`。它包含：
* **64 个图层** 及其全部设置（名称、颜色、顺序、操作、刀具、深度、步距、进给、主轴转速、方向、进刀方式、连接桥和手动放置的连接桥、冷却液……），
* **材料**（类型、颜色、厚度、首次加工）和 **项目设置**（材料块的尺寸、程序在其上的零点、Z 从底部算起），
* **设备快照**（名称和工作区），
* **图层使用的刀具**，以便在刀具库中没有这些刀具的地方也能打开项目。

打开来自 LightCreator 的项目（或普通的 SVG、PDF 或 LightBurn 文件）会得到默认图层；其其他部分（`laser`）会被保留，并在保存时写回。`mill` 格式比程序所知的更新的项目会被拒绝并给出提示。数值错误的图层会被替换为其默认值；缺少的刀具会被添加到 **我的刀具**（**My bits**）中。

设备本身不在项目中，只有其快照：当前使用的设备是在启动界面上选择的设备。当快照中的工作区与该设备的工作区不同时，状态栏会发出警告。

项目的描述（**描述**（**Description**）标签页）是共享容器的一部分，因此 LightCreator 会显示相同的文本。MillCreator 还会把它作为 `(Note: …)` 注释写在 G-code 的开头（参见 [3D 视图与 G-code](3D-View-and-G-code-ZH#导出-g-code)）。

## 密码保护

> ⚠️ 本节由英文版机器翻译而成。

项目可以用密码保护：在 LightCreator、MillCreator 和 PenCreator 的 **项目设置…**（**Project setup…**）中，以及 BaseCreator 的 **文件 → 页面设置…**（**File → Page setup…**）中的 **保护**（**Protection**）部分设置。

* **所有者密码**：可以做任何事（编辑、复制、导出、更改或移除保护）。
* **打开密码**（可选）：可以打开项目、查看、生成 G-code 并在机器上运行，也可以更改材料和图层设置（速度、功率、遍数、深度、刀具、笔），但不能编辑、复制、以图形格式导出（SVG、DXF、Illustrator、LightBurn …）或打印图形。此时内置网页不显示图形。
* 只有所有者密码时，其他人无法打开文件。没有密码文件完全无法读取，**忘记的密码无法找回**。
* 用打开密码打开的项目可以用所有者密码解锁，无需重新打开：在设置的 **保护** 部分（**所有者密码**、**解锁**），或在其标签页的菜单（右键）中选择 **用所有者密码解锁…**。该菜单还有 **项目信息…** 和项目设置。

文件仍是带有 `protected_cre` 键的 JSON 文本；其中的项目用 **XChaCha20-Poly1305** 以随机 256 位密钥加密，该密钥为每个密码各存一份，并用 **Argon2id**（64 MiB、3 遍、独立盐值）由密码生成的密钥加密。每次保存使用新的 nonce；被修改的文件无法打开。密码至少 8 个字符，打开密码必须与所有者密码不同。

打开密码所禁止的内容由程序执行，就像 PDF 的所有者密码一样：知道它的人原则上可以用其他工具解密项目。请自己保管好所有者密码。
