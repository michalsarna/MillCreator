# 키보드 단축키

Windows와 Linux의 Ctrl은 macOS에서 **Cmd**입니다. 단축키는 편집기에서 동작하며(시작 화면에서는 동작하지 않음), 텍스트 필드에 키보드 입력이 가 있는 동안에는 어떤 단축키도 동작하지 않습니다. 이름, 숫자 또는 G-code를 입력하는 동안 Ctrl+C, Delete, 글자 키는 필드에 속합니다.

## 메뉴의 단축키

메뉴 항목 옆에 표시되는 단축키입니다([메뉴](Menus-KO) 참고). 도면이 열리면 Windows, Linux, macOS에서 바로 동작하며, 그 순간 회색인 항목은 아무 일도 하지 않습니다. macOS 메뉴 막대에 대해서는 [아래](#macos)를 참고하십시오.

| 단축키 | 항목 | 메뉴 |
|---|---|---|
| Ctrl+N | **새로 만들기**(New) | 파일 |
| Ctrl+O | **열기…**(Open…) | 파일 |
| Ctrl+S | **저장**(Save) | 파일 |
| Ctrl+Shift+S | **다른 이름으로 저장…**(Save as…) | 파일 |
| Ctrl+Q | **종료**(Quit) | 파일 (macOS: **MillCreator** 메뉴의 Cmd+Q) |
| Ctrl+Z | **실행 취소**(Undo) | 편집 |
| Ctrl+Y, Ctrl+Shift+Z | **다시 실행**(Redo) | 편집 |
| Ctrl+C | **복사**(Copy) | 편집 |
| Ctrl+V | **붙여넣기**(Paste) | 편집 |
| Ctrl+D | **복제**(Duplicate) | 편집 |
| Delete 또는 Backspace | **삭제**(Delete) (*Del*로 표시) | 편집 |
| Ctrl+A | **모두 선택**(Select all) | 편집 |
| Ctrl+G | **그룹**(Group) | 정렬 |
| Ctrl+Shift+G | **그룹 해제**(Ungroup) | 정렬 |
| Ctrl+L | **잠금**(Lock) | 정렬 |
| Ctrl+Shift+L | **잠금 해제**(Unlock) | 정렬 |
| N | **노드 편집**(Edit nodes) | 정렬 (노드 도구, 아래 참고) |
| Ctrl+= (Ctrl++로 표시) | **확대**(Zoom in) | 보기 |
| Ctrl+- | **축소**(Zoom out) | 보기 |
| Ctrl+Shift+0 | **베드를 창에 맞추기**(Fit bed to window) | 보기 |
| Ctrl+Shift+9 | **모든 개체 맞추기**(Fit all objects) | 보기 |
| Ctrl+Shift+P | **작업 3D 보기…**(3D view of the job…) | 밀링 |
| Ctrl+E | **G-code 내보내기…**(Export G-code…) | 밀링 |

단축키 하나는 한 항목에만 속합니다(프로그램의 테스트가 이를 확인합니다). Ctrl+Shift+G는 **그룹 해제**이고, G-code는 **Ctrl+E**로 내보냅니다.

## 편집기의 기타 단축키

| 단축키 | 기능 |
|---|---|
| Delete, Backspace | 선택한 도형을 삭제합니다. 노드 도구에서 노드를 선택한 상태라면 노드를 삭제합니다. |
| Esc | 선택을 해제합니다(펜으로 그리고 있는 선의 점도 지웁니다). |
| Esc 두 번 | 0.5초 안에 Esc를 한 번 더 누르면 **선택**(Select) 도구로 돌아갑니다. |
| Space (누르고 있기) | 어떤 도구에서든 화면을 이동합니다. 놓으면 원래 도구로 돌아갑니다. |
| 화살표 키 | 선택 항목을 1 mm 옮깁니다. **Shift** + 화살표 = 10 mm (제어 탭에서 **키보드**(Keyboard)가 체크되어 있을 때는 제외). |
| G, I | 다각형과 나선: 작은 창에서 변의 수나 감은 횟수를 설정하며, 마지막으로 그린 도형에도 적용됩니다. |
| Ctrl+1 … Ctrl+9, Ctrl+0 | 탭 1 … 9의 도면을 보여 줍니다. Ctrl+0은 탭 10입니다. |
| Ctrl+W | 표시 중인 도면을 닫습니다(저장하지 않은 작업에 대해 묻습니다). |
| Enter | 펜 도구의 선을 끝냅니다(오른쪽 클릭이나 더블 클릭으로도 끝납니다). |

## 도구 (글자 하나)

Ctrl 없이 글자를 누르면 왼쪽 팔레트의 도구가 선택됩니다. 글자는 도구 이름에 들어 있습니다(툴팁과 **삽입**(Insert) 메뉴에서 볼 수 있습니다).

| 단축키 | 도구 | 단축키 | 도구 |
|---|---|---|---|
| V | **선택 (V)**(Select) | L | **선 (L)**(Line) |
| N | **노드 편집 (N)**(Node edit) | P | **폴리라인 / 펜 (P)**(Polyline / pen) |
| R | **사각형 (R)**(Rectangle) | T | **텍스트 (T)**(Text) |
| E | **타원 (E)**(Ellipse) | H | **이동 (H)**(Pan) |
| Y | **삼각형 (Y)**(Triangle) | Z | **확대 (Z)**(Zoom in) |
| S | **별 (S)**(Star) | X | **축소 (X)**(Zoom out) |
| G | **다각형 (G)**(Polygon) | | |
| K | **하트 (K)**(Heart) | M | **자 (M)**(Ruler) |
| I | **나선 (I)**(Spiral) | | |

## 작업 영역에서의 마우스

| 동작 | 기능 |
|---|---|
| 휠 또는 터치패드 핀치 | 포인터를 중심으로 확대/축소합니다. |
| 가운데 또는 오른쪽 버튼 끌기 | 작업 영역 위와 그 옆에서 화면을 이동합니다(**이동**(Pan) 도구에서는 왼쪽 버튼도 가능합니다. 움직이지 않은 오른쪽 클릭은 메뉴를 엽니다). |
| Shift + 클릭, Ctrl + 클릭 | 도형을 선택에 추가하거나 선택에서 뺍니다. |
| 오른쪽 클릭 (선택 도구) | 포인터 아래의 도형을 선택하고 컨텍스트 메뉴를 엽니다. |
| 확대/축소 도구에서 Shift | 확대와 축소를 바꿉니다. |
| 다른 창 영역의 도면(또는 그 탭)을 클릭 | 그 도면을 활성 도면으로 만듭니다. |
| 탭을 가운데 클릭 | 탭을 닫습니다. |

## 미리 보기 (3D 보기)

| 동작 | 기능 |
|---|---|
| 왼쪽 끌기 | 시점을 회전합니다. |
| 오른쪽 또는 가운데 끌기 | 화면을 이동합니다. |
| 휠 | 확대/축소합니다. |
| 더블 클릭 | 처음 시점으로 돌아갑니다(**보기 초기화**(Reset view)와 같음). |

**G-code 분석**(G-code analysis)(파일 → G-code 파일 보기…(File → View G-code file…))에서는 끌면 평면 파일은 이동하고 3D 파일은 회전합니다(오른쪽 끌기 또는 Shift+끌기로 이동). 휠은 확대/축소하고 **Esc**는 창을 닫습니다.

## 창과 필드

* **Esc**는 *닫기 전에 작업을 저장할까요?*(*Save your work before closing?*) 질문을 취소하고(**취소**(Cancel)와 같음), 프로그램 원점의 **작업 영역에서 고르기**(Pick on the work area)를 취소합니다.
* **레이어 프리셋**(Layer presets) 창에서 Enter는 프리셋의 새 이름을 확정하고 Esc는 버립니다.

## 키보드로 조그하기

**제어**(Control) 탭에서 **키보드**(Keyboard)가 체크되어 있으면(기본값은 꺼짐) 화살표 키로 X와 Y를, **Page Up** / **Page Down**으로 Z를 그 위에서 고른 스텝만큼 움직입니다. 필드에 키보드 입력이 가 있거나 기계가 작업 중이면 아무것도 움직이지 않습니다. [기계 제어](Machine-Control-KO)를 참고하십시오.

## macOS

macOS에서 프로그램은 시스템 메뉴 막대를 사용합니다. 이 페이지의 모든 단축키는 Ctrl 대신 Cmd로 Windows와 Linux에서처럼 동작합니다.

* 시스템 메뉴 막대는 **새로 만들기**(Cmd+N), **열기…**(Cmd+O), **저장**(Cmd+S), **다른 이름으로 저장…**(Cmd+Shift+S), **종료**(Cmd+Q, **MillCreator** 메뉴)의 단축키를 가져가 해당 항목 옆에 표시합니다.
* 나머지 모든 단축키는 다른 시스템과 똑같이 프로그램이 직접 처리합니다: Cmd+E, Cmd+Shift+P, Cmd+L, Cmd+Shift+L, Cmd+= / Cmd+-, Cmd+Shift+0 / Cmd+Shift+9, 편집 단축키, Cmd+1 … Cmd+0, Cmd+W, 도구의 글자 키. 시스템 메뉴 막대는 이 단축키들을 항목 옆에 표시하지 않지만, 이 페이지와 Windows 및 Linux의 메뉴 막대에는 표시됩니다.
