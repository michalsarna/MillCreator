# 窗格与标签页

如何布置 MillCreator 的工作区：图纸与其预览并排、同时显示两张图纸、把预览放到第二台显示器上。这里的所有内容在 LightCreator、MillCreator 和 PenCreator 中都相同。

```
+--------------------------------------------+------------------+
| drawing A | drawing B | + || Preview | +    | Properties | ... |
|---------------------------||----------------|                  |
|                           ||                |   right panel    |
|          pane 1           ||     pane 2     |  (its own tabs)  |
|                           ||                |                  |
+--------------------------------------------+------------------+
```

## 什么是标签页

工作区在其上方的一条栏中显示 **标签页**（**tabs**）：

* 每张打开的 **图纸**（标签页上的圆点表示有未保存的更改）；
* **预览**（**Preview**）；
* **预览 G-code**（**Preview G-code**）：以文本形式显示的项目 G-code；
* 某个文件的 **G-code 分析**（**G-code analysis**）；
* **摄像头视图**（**Camera view**），当它以标签页形式显示在工作区中时。

栏末尾的 **+** 用于新建图纸。每个标签页只存在一个：打开一个已经打开的项目会显示其标签页，每个项目只有一个预览、一个 G-code 文本和一个摄像头视图。

**窗格**（**pane**）是工作区中带有自己标签栏的一部分。**最多有三个窗格**。只有一个窗格时（初始状态），你只能看到一条标签栏。

## 创建第二个窗格

请先打开至少 **两个标签页**：窗格需要有自己的标签页，因此只有一个标签页时不会发生任何变化。然后可以：

* 选择 **视图 → 分屏：左右并排**（**View → Split view: side by side**）或 **视图 → 分屏：上下排列**（**View → Split view: one above the other**）：标签栏中的最后一个标签页会移到新窗格；或者
* 右键单击你要移动的标签页，选择 **移动到窗格 2**（**Move to pane 2**）。

## 创建第三个窗格

在含有两个或更多标签页的窗格中右键单击一个标签页，然后选择 **移动到窗格 3**（**Move to pane 3**）。**分屏** 条目只能创建第二个窗格。

## 移动标签页

* 把 **标签页拖到** 另一个窗格的标签栏上：一条线会显示它将落在哪里。或者把它放到该窗格的主体区域上（窗格会出现边框）：标签页会放到其标签栏的末尾。
* 沿着它自己的标签栏拖动可以改变顺序。
* 或者使用其菜单（右键单击）：**移动到窗格 N**（**Move to pane N**）。

拖动只能在已有的窗格之间移动标签页：新窗格需要通过菜单创建。

## 更改尺寸和方向

* **拖动两个窗格之间的分隔线** 以更改它们的尺寸。窗格不会小于 160 点。
* **双击分隔线** 使各窗格大小相等。
* 有两个或三个窗格时，**视图 → 分屏：…**（**View → Split view: …**）会改变方向：左右并排或上下排列。标签页保持在原来的位置。

## 回到一个窗格

* **视图 → 单视图**（**View → Single view**）把所有标签页重新放回一个窗格中。
* 关闭窗格中的最后一个标签页会关闭该窗格，其余窗格随之合拢。把它的最后一个标签页移走也是一样。
* 关闭最后一张打开的图纸时（如果有未保存的工作，会先询问是否保存）会询问 **关闭程序吗？**（**Close the program?**）：**关闭程序**（**Close the program**）关闭程序，**返回启动界面**（**Back to the start screen**，或按 Escape）显示启动界面。

## 关闭标签页

单击其叉号，用 **鼠标中键** 单击它，或在其菜单（右键单击）中选择 **关闭标签页**（**Close tab**）。有未保存更改的图纸会先询问。

## 工具作用于哪张图纸

只有一张图纸是 **当前**（**active**）图纸：工具、菜单和快捷键都作用于它。另一个窗格中的图纸仅供查看，有自己的缩放。**单击它或其标签页，使它成为当前图纸。**

## 在单独窗口中显示标签页

**预览** 和 **G-code 文本** 可以移到单独的窗口中，例如放在第二台显示器上；**摄像头视图** 有它自己的单独窗口（其三种方式之一，在视图中选择）。图纸不能这样做。

1. 右键单击标签页，选择 **在单独窗口中打开**（**Open in a separate window**）。
2. 把窗口移到你想要的位置。它会记住自己的位置和大小。
3. 窗口顶部的 **返回主窗口**（**Back to the main window**），或关闭该窗口，会把标签页放回你最后使用的窗格中。

**视图 → 单视图** 不会影响这些窗口。

## 三种工作方式

* **图纸和预览并排：** 打开预览（**铣削 → 任务的 3D 视图…**（**Milling → 3D view of the job…**）或 **预览…**（**Preview…**）按钮；Ctrl+Shift+P），然后选择 **视图 → 分屏：左右并排**。检查移到窗格 2 的是否是预览标签页；如果不是，把它拖过去。
* **同时显示两张图纸：** 打开两张图纸，然后选择 **视图 → 分屏：左右并排**。单击你要编辑的那张：另一张会保持在视野中，并有自己的缩放。
* **在第二台显示器上预览：** 右键单击预览标签页，选择 **在单独窗口中打开**，然后把窗口拖到那台显示器上。

## 右侧面板

右侧的面板与窗格是分开的。它有自己的标签页：**属性**（**Properties**）、**图层**（**Layers**）、**材料**（**Material**）、**设备**（**Device**）、**控制**（**Control**）、**控制台**（**Console**）、**剪贴画**（**Clipart**）、**描述**（**Description**）和 **录制**（**Recording**，每个摄像头一个面板、移到一旁拍照、长线条），以及在需要时出现的摄像头或插件标签页（这两者始终位于行末）。

* 在其行内 **拖动标签页** 可以改变顺序。顺序会被记住。
* **拖动面板的左边缘** 可以改变其宽度。
* 行首的箭头用于 **隐藏面板**：标签页名称会竖排保留在一条窄条上。单击某个名称会打开面板并定位到该标签页；窄条上的按钮（**显示面板**（**Show the panel**））会重新打开面板。

右侧面板的标签页和工作区的标签页不能混用：不能把一个拖到另一个中。

## 会被记住的内容

窗格、其中的标签页、方向和尺寸都会随程序设置保存，并在你再次启动程序时恢复，已不再打开的内容的标签页除外。右侧面板标签页的顺序以及面板是否隐藏也会被记住。
