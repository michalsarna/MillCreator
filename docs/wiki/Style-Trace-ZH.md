# 风格描摹

**排列 → 风格描摹…**（**Arrange → Style trace…**）用 21 种风格之一把所选图片重新绘制为线条，可直接用于雕刻：波浪线、螺旋、波纹、半色调圆、排线、点画、一笔画、流线、素描等。图片的右键菜单以及 **属性**（**Properties**）中的 **图片**（**Image**）部分也有此命令。它在 LightCreator、MillCreator、PenCreator 和 BaseCreator 中的用法相同。

## 分步说明

1. 选择一张图片，然后选择 **风格描摹…**（**Style trace…**）。
2. 选择 **风格**（**Style**）；其下方的一行文字说明它绘制什么。有些风格有 **类型**（**Kind**）（例如点画可以用点、短划或三角形）。
3. 调整风格的设置。预览完全按照线条放到图纸上的样子显示；预览在后台计算，因此窗口不会卡住（旧线条会保持灰色，直到新线条准备好）。按钮下方的一行文字说明共有多少条线以及它们的总长度。
4. **色调**（**Tone**）：**黑点**（**Black point**）和 **白点**（**White point**）截去最暗和最亮的灰度，**伽马**（**Gamma**）使中间调变亮（大于 1）或变暗，**描摹亮区**（**Trace the light areas**）互换暗与亮。
5. **放到图层**（**Put on the layer**）：程序选择第一个使用 **沿线加工**（**follows the line**）的空图层（默认为 **雕刻**（**Engrave**），使用 V 形刀）；描摹会把图层设置为 *沿线加工*（*Follow the line*）。线条以图层的深度雕刻：请保持较小的深度（0.2 至 0.5 mm）并使用尖头刀具，否则线条会相互连在一起。你可以从列表中选择另一个图层。
6. **之后删除图片**（**Delete the image afterwards**）会在线条生成后移除图片。
7. **描摹**（**Trace**）把线条作为一个图形放到图纸上，位于图片的位置（随图片移动、旋转和缩放）。**编辑 → 撤销**（**Edit → Undo**）可以撤回。

使用随机性的风格（点画、流线、素描、涂鸦、方块、针线、Truchet 拼贴）有一个 **随机图案**（**Random pattern**）编号：相同的编号每次都会生成相同的线条，**换一个**（**Another**）尝试另一个编号。

## 风格

| 风格 | 绘制内容 | 设置 |
|---|---|---|
| **波浪线**（**Squiggle**） | 一行行线条，在图片较暗处波动得更快、更高。 | **线条间距**（**Spacing of the lines**）、**波高**（**Wave height**）、**每毫米波数**（**Waves per mm**）、**角度**（**Angle**）；类型：从边到边的行，或 **在白色处抬笔**（**Lift the pen over white**）。 |
| **锯齿**（**Sawtooth**） | 同样的行，但为锯齿形。 | 同波浪线。 |
| **弹簧**（**Springs**） | 一行行像拉伸弹簧的线圈，越暗处线圈越大。 | 同波浪线。 |
| **螺旋**（**Spiral**） | 从中心开始的一条螺旋线，在阴影处摆动更大（即其他程序中的 *Frequency lines*）。 | **圈距**（**Spacing of the turns**）、**波高**（**Wave height**）、**每毫米波数**（**Waves per mm**）；类型：波浪或锯齿。 |
| **波纹**（**Waves**） | 按暗度抬起的一行行线条，就像从侧面看到的地形；前面的行会遮住后面的内容。 | **线条间距**（**Spacing of the lines**）、**波纹高度**（**Height of the waves**）；类型：遮挡后面的内容，或完整绘制每一行。 |
| **半色调圆**（**Halftone circles**） | 一个圆的网格，圆的大小随色调变化，就像印刷的照片。 | **单元尺寸**（**Cell size**）、**最大圆**（**Largest circle**）、**环间距**（**Spacing of the rings**）、**角度**（**Angle**）；类型：圆、环（用环填充）或螺旋。 |
| **蚀刻**（**Etching**） | 分层排线，就像旧式版画：每加深一级色调，就增加一个方向的线条。 | **线条间距**（**Spacing of the lines**）、**色调级数**（**Tone levels**，1 至 6）、**角度**（**Angle**）；类型：直线或波浪线。 |
| **方块**（**Squares**） | 一个方块套方块的网格，越暗处方块越多。 | **单元尺寸**（**Cell size**）、**每个单元最多方块数**（**Most squares in a cell**）、**抖动**（**Shake**，随机旋转）、**角度**（**Angle**）。 |
| **针线**（**Needles**） | 网格上的短笔画，越暗处越长。 | **单元尺寸**（**Cell size**）、**笔画长度**（**Stroke length**）、**角度**（**Angle**）；类型：沿形状、按角度或随机。 |
| **Truchet 拼贴**（**Truchet tiles**） | 随机旋转的四分之一圆拼贴，越暗处圆弧越多。 | **拼贴尺寸**（**Tile size**）、**每块拼贴最多圆弧数**（**Most arcs in a tile**）。 |
| **等高线**（**Contour lines**） | 等亮度线，就像地图上的等高线。 | **平滑**（**Smoothing**）、**色调级数**（**Tone levels**，2 至 40）。 |
| **希尔伯特曲线**（**Hilbert curve**） | 一条空间填充曲线，越暗处转折越细密。 | **最小步长**（**Smallest step**）、**色调级数**（**Tone levels**）；类型：一条线或 **在白色处抬笔**（**Lift the pen over white**）。 |
| **点画**（**Stippling**） | 按色调分布的点（加权 Voronoi 点画）：阴影处密集，亮处稀疏。 | **点数**（**Number of dots**）、**点大小**（**Dot size**）；类型：点、按色调变化的圆、短划或三角形。 |
| **一笔画 (TSP)**（**One line (TSP)**） | 把点画的点连成一条不自相交的线，绘制时无需抬笔。 | **点数**（**Number of dots**，最多 15 000）。 |
| **三角形和单元**（**Triangles and cells**） | 在按色调分布的点上生成三角形网格（Delaunay），或点周围的单元网格（Voronoi）。 | **点数**（**Number of dots**）；类型：三角形或单元。 |
| **线稿**（**Line art**） | 仅以线条表示图片的边缘。 | **最小细节**（**Smallest detail**）、**边缘灵敏度**（**Edge sensitivity**）、**最短线条**（**Shortest line**）；类型：边缘，或边缘和暗区。 |
| **流线**（**Flow lines**） | 沿形状流动的长线条，越暗处越密集。 | **最小间隙**（**Smallest gap**，在最暗处）、**最大间隙**（**Largest gap**，在最亮处）、**曲线尺寸**（**Size of the curves**）、**角度**（**Angle**）；类型：沿形状或随机流场。 |
| **素描**（**Sketch**） | 在图片最暗处排布许多短直线笔画，就像铅笔素描。 | **笔画长度**（**Stroke length**）、**笔画数**（**Number of strokes**）、**单笔墨量**（**Ink of one stroke**，一笔吸收多少暗度）；类型：独立笔画或连成链的笔画。 |
| **涂鸦**（**Scribble**） | 一条带圈的游走线条，把暗部涂满。 | **圈大小**（**Loop size**）、**线条长度**（**Length of the line**，米）、**单遍墨量**（**Ink of one pass**）。 |
| **V 雕**（**V-carve**） | 按角度排列的线条，每条线的宽度取决于沿线图片的暗度：亮处细，阴影处宽，就像 V 形刀切得越深就越宽。每条线被切分成小段，每段的亮度决定其宽度；每条线都是一条闭合轮廓。变体：**平滑**（**Smooth**，穿过各段的平滑曲线）或 **棱角**（**Angular**，各段之间为直线）。 | **线条宽度**（**Width of the lines**，也是最宽线条的宽度）、**分段长度**（**Length of the pieces**）、**最细线条**（**Thinnest line**，白色处占宽度的比例；0：该处没有线条）、**角度**（**Angle**）。 |
| **几何多边形**（**Geometric polygons**） | 把图片的暗色形状分割成多边形（三角形和四边形），图片有边缘的地方多边形更多，多边形之间以及轮廓周围留有间隙：一幅几何（低多边形）图片，可用作墙饰或模板。外轮廓沿形状走，多边形被裁切到外轮廓内。也可用 **排列 → 几何多边形…**（**Arrange → Geometric polygons…**）。变体：**三角形和四边形**（**Triangles and quadrangles**）、**三角形**（**Triangles**）；更换 **种子**（**seed**）会得到不同的多边形；色调设置（黑点）决定哪些是暗色形状。 | **多边形间隙**（**Gap between the polygons**，0：每条边为一条线）、**多边形数量**（**Number of polygons**）、**跟随边缘**（**Follow the edges**，0：均匀，1：只按边缘）。 |

## 须知

* 设置以图片的毫米为单位，因此较大的图片会得到更多的线条，而不是更粗的线条。请使线条间距大于笔、激光光斑或刀具的宽度。
* 点是一个小的闭合圆，因此它像其他线条一样被绘制、烧刻或雕刻。
* **一笔画 (TSP)**、**螺旋** 和 **希尔伯特曲线** 以一次长距离移动绘制；其他风格会按能使线条之间移动距离较短的顺序排列。
* 非常精细的设置会产生大量的点：当绘图会变慢时，按钮下方的一行文字会发出警告，结果最多为两百万个点。
* 当风格需要更高对比度时，请先调整图片（**排列 → 调整图片…**（**Arrange → Adjust image…**）：亮度、对比度、色阶）。

## 图片风格面板

选中图片时，侧面板会有一个 **图片风格**（**Picture styles**）标签页（选中图片时自动打开，没有选中图片时消失）。其顶部有一个与面板同宽的橙色按钮，用于打开 **编辑图片…**（**Edit image…**，照片编辑器），下方的按钮打开 **描摹图片…**（**Trace image…**）；再往下像图库一样，每种风格都有一张小图（用该风格绘制的一个三角形）。单击其中一张会打开 **风格描摹**（**Style trace**），并已选中该风格。
