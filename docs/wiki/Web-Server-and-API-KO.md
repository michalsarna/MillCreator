# 웹 서버와 API

**설정 → 프로그램 옵션… → 웹 서버와 API**(Settings → Program options… → Web server and API)는 MillCreator에 내장된 작은 웹 서버를 켭니다. **기본값은 꺼짐**입니다. 브라우저(휴대폰 포함)에서 기계, 프로젝트, 카메라의 상태를 보여 주며, 다른 프로그램을 위한 API를 제공합니다.

**모든 요청에는 접근 문구가 필요합니다**(같은 옵션에서 옆의 *저장*(*Save*) 버튼으로 설정합니다. 처음 값은 `MillCreator`이므로 다른 컴퓨터를 들이기 전에 바꾸십시오). 브라우저가 이를 묻습니다(사용자 이름은 아무것이나, 문구는 비밀번호 필드에). 프로그램은 HTTP Basic 인증으로 보냅니다. 예: `curl -u any:MillCreator http://localhost:8766/api/status`. 잘못된 문구에는 잠시 기다린 뒤 401로 응답합니다. **암호화가 없으므로** 네트워크를 엿들을 수 있는 누구나 문구와 데이터를 읽을 수 있으며, 문구는 `the settings of the program`에 base64로 보관됩니다(한눈에 읽히지는 않지만 base64는 인코딩이지 암호화가 아닙니다). 기본적으로 서버는 이 컴퓨터에서만 수신합니다(`http://localhost:8766`). *네트워크의 다른 컴퓨터에서 접근 가능*(*Reachable from other computers on the network*)을 켜면 모든 인터페이스에서 수신하므로, 네트워크의 누구나 기계를 보고 멈추거나 움직일 수 있습니다. 신뢰하는 네트워크에서만 사용하고, 포트를 인터넷에 절대 열지 마십시오.

같은 서버가 제품군의 모든 프로그램(LightCreator, MillCreator, PenCreator, BaseCreator)에 있으며, 한 컴퓨터에서 모두 실행할 수 있도록 각각 자체 포트를 씁니다: **8765** LightCreator, **8766** MillCreator, **8767** PenCreator, **8768** BaseCreator(BaseCreator는 프로젝트만 보여 줍니다).

## 웹 페이지
`http://localhost:<port>/`에는 장치, 그 상태, 위치, 작업의 경과 시간 대 추정 시간, 진행 막대가 있는 막대와 **테마**(Theme) 목록이 있습니다. 페이지는 프로그램의 색 구성표로 시작합니다(18가지 구성표가 모두 제공되며, 선택은 브라우저에 보관됩니다).

컴퓨터에서 페이지는 두 열입니다. 왼쪽 3분의 2에는 **카메라**(목록에서 활성 카메라를 고르며, 이는 장치의 활성 카메라를 바꿉니다. 카메라가 없으면 큰 X 표시된 카메라가 보입니다), 오른쪽 3분의 1에는 **제어판**(STOP, Home, Cancel jog, 그리고 조그 화살표 여덟 개; 제어 탭에서 고른 길이만큼 한 스텝)과 그 아래에 그림으로 된 **프로젝트**가 있습니다. 그림을 더블 클릭하면(또는 전체 화면 버튼) 창 전체로 확대되며, 확대, 축소, 이동, 보기 초기화 버튼이 있습니다. 마우스 휠, 끌기, 두 손가락 핀치도 동작하며 Esc로 닫습니다.

카메라 화면은 프로그램에서처럼 돌아가 있습니다. 장치 설정의 *카메라 회전*(*Camera rotation*)이 기본값이며(시계 방향 0°, 90°, 180°, 270°), 화면 위의 목록에서 다른 회전을 고를 수 있고 브라우저가 카메라마다 기억합니다. `GET /api/cameras`는 각 카메라의 `rotation`과 `rotated`(스냅숏에 이미 적용된 회전량)를 알려 줍니다.

휴대폰에서 페이지는 한 열입니다: 상태, 카메라, 프로젝트, 그리고 맨 아래에 제어판.

## API
따로 언급하지 않는 한 모든 응답은 JSON입니다. 명령에는 `POST`가 필요합니다.

| 요청 | 기능 |
|---|---|
| `GET /api/status` | 프로그램, 장치(이름, 컨트롤러, 연결 여부, 상태, X, Y), 작업(실행 중 여부, 완료 / 전체 줄 수, 경과 및 추정 초), 프로젝트(파일 이름, 리비전, 설명) |
| `GET /api/project.svg` | 프로젝트를 SVG로 |
| `GET /api/cameras` | 카메라 목록: 인덱스, 이름, 활성화 여부, 활성 카메라 여부, `rotation`, `rotated`, `url`(카메라 자체의 http / https 주소, 또는 `null`), `snapshot` |
| `GET /api/camera.jpg` | 카메라 보기의 최신 화면을 JPEG로(프로그램에서 카메라 보기가 열려 있을 때만; 그렇지 않으면 503) |
| `POST /api/stop` | 실행 중인 작업을 멈춤(STOP과 같음) |
| `POST /api/home` | 원점 복귀, 연결되어 있고 실행 중인 작업이 없을 때만 |
| `POST /api/cancel-jog` | 조그 취소 |
| `POST /api/jog?dir=…` | 조그 한 스텝: `up`, `down`, `left`, `right`, `up-left`, `up-right`, `down-left`, `down-right`; 연결되어 있고 실행 중인 작업이 없을 때만, 허용된 영역 안에서 |
| `POST /api/camera/select?index=N` | 카메라 N을 활성 카메라로 만듦 |

명령은 그에 해당하는 버튼의 규칙을 따릅니다. 여기 있는 어떤 것도 아직 실제 하드웨어에서 시험하지 않았으며, 서버 자체는 테스트로 검증되어 있습니다.
